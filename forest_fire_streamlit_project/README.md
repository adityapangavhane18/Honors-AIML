
# Forest Fire Burned Area Prediction - Streamlit Project

## Files Included
- app.py
- train_model.py
- requirements.txt
- data/forestfires.csv
- forest_fire_model.pkl (generated after training)

## Steps to Run

1. Download the dataset and save it inside data/forestfires.csv

2. Install requirements:
python -m pip install -r requirements.txt

3. Train the model:
python train_model.py

4. Run the Streamlit app:
streamlit run app.py
